| Nhu cầu                            | Mô tả                                                     |
| ---------------------------------- | --------------------------------------------------------- |
| Chụp nhanh thông tin trên màn hình | Lỗi phần mềm, hóa đơn, đoạn chat, giao diện web, tài liệu |
| Ghi chú trực tiếp lên ảnh          | Khoanh vùng, gạch chân, highlight, vẽ bằng bút            |
| Sao chép vào clipboard             | Dán nhanh vào Zalo, Teams, Word, email, ticket            |
| Lưu thành file                     | Lưu ảnh làm bằng chứng, tài liệu, hướng dẫn               |
| Upload                             | Upload file lên API, được cấu hình trong appsetting.json -> Lấy được url file ảnh server trả về |
 
 

User nhấn New / Ctrl + Win + Print
        ↓
Hệ thống phủ overlay mờ lên màn hình
        ↓
User chọn chế độ chụp
        ↓
User kéo chuột / chọn cửa sổ / chọn toàn màn hình
        ↓
Ảnh được capture
        ↓
Ảnh được đưa vào clipboard và/hoặc mở trong editor
        ↓
Upload ảnh lên API
        ↓
Lấy url ảnh API trả về



| Phím tắt              | Chức năng                           |
| -----------------     | ----------------------------------- |
| `Ctrl + Win + Print`  | Mở giao diện chụp ảnh màn hình      |
| `Ctrl + C`            | Copy ảnh vào clipboard              |
| `Ctrl + S`            | Lưu ảnh                             |
| `Ctrl + U`            | Upload ảnh lên server               |
| `Ctrl + N`            | Tạo ảnh chụp mới                    |


| Định dạng | Đặc điểm                        |
| --------- | ------------------------------- |
| PNG       | Rõ nét, phù hợp UI/screenshot   |
| JPG/JPEG  | Dung lượng nhẹ hơn, có nén      |
| GIF       | Ít dùng hơn cho screenshot tĩnh |

 Đây là Curl của API, hãy update lại API tương ứng:
curl -X 'POST' \
  'http://192.168.1.69:55834/api/Files/upload' \
  -H 'accept: text/plain' \
  -H 'Content-Type: multipart/form-data' \
  -F 'file=@38u9mb.jpg;type=image/jpeg' \
  -F 'serviceName=pbt'
